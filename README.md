## 📌 Tính Năng Chính (Key Features)

- 📱 **Responsive Design**: Hiển thị tối ưu trên mọi thiết bị (Desktop, Tablet, Mobile).
- 🎨 **Giao diện hiện đại (UI/UX)**: Tối giản, thân thiện với người dùng, tích hợp Chế độ Sáng/Tối (Light/Dark Mode).
- 🔍 **Tìm kiếm & Bộ lọc**: Tìm kiếm sản phẩm/bài viết theo thời gian thực, lọc theo danh mục, giá cả.
- 🛒 **Giỏ hàng & Thanh toán**: Thêm/xóa sản phẩm, tính tổng tiền tự động và lưu trữ giỏ hàng local.
- ⚡ **Tối ưu hiệu năng**: Tốc độ tải trang nhanh, chuẩn SEO Google.

### Frontend
- **HTML5 & CSS3**: Dựng cấu trúc và tạo style cơ bản.
- **JavaScript (ES6+)**: Xử lý logic và tương tác giao diện.
- **Framework/Library**: [Ví dụ: React.js / Vue.js / Tailwind CSS / Bootstrap 5]

### Tools & Hosting
- **Version Control**: Git & GitHub
- **Deployment**: GitHub Pages / Vercel / Netlify
